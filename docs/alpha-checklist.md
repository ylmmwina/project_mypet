# Чекліст демонстрації Alpha Version

Цей чекліст використовується для ручної перевірки основного сценарію роботи проєкту **MyPet** під час демонстрації alpha-версії.

## Основний сценарій користувача

- [ ] Зареєструвати нового користувача
- [ ] Увійти в акаунт створеного користувача
- [ ] Створити нового улюбленця
- [ ] Перевірити, що улюбленець зберігається після перезавантаження сторінки
- [ ] Погодувати улюбленця
- [ ] Покласти улюбленця спати
- [ ] Відкрити магазин
- [ ] Купити предмет
- [ ] Відкрити інвентар
- [ ] Використати предмет з інвентарю
- [ ] Запустити міні-гру
- [ ] Завершити міні-гру
- [ ] Перевірити, що після міні-гри збільшилась кількість монет
- [ ] Перевірити, що після міні-гри збільшився XP
- [ ] Перевірити, що рівень улюбленця може зростати завдяки XP
- [ ] Перевірити зміну фонової локації
- [ ] Перевірити live-оновлення стану улюбленця через Socket.IO
- [ ] Запустити автоматизовані тести командою `npm test`

## Очікуваний результат

Alpha-версія повинна дозволяти користувачу зареєструватися, увійти в акаунт, створити та доглядати за улюбленцем, користуватися магазином та інвентарем, отримувати нагороди за міні-гру, бачити зміну фонових локацій і успішно проходити автоматизовані тести.
