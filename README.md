# 🐾 MyPet: Навчальний Fullstack Tamagotchi Проєкт

## 🚀 1. Розвиток проєкту у 2 семестрі

У другому семестрі проєкт **MyPet** продовжує розвиватися як навчальний fullstack-застосунок у стилі класичних ігор-тамагочі.  
Основна мета — розширити базову ігрову механіку, додати новий функціонал та посилити технічну складову проєкту.

### ✅ Alpha Version Features

Альфа-версія проєкту включає:

- реєстрацію та авторизацію користувачів;
- збереження профілів користувачів;
- підтримку кількох улюбленців для одного користувача;
- характеристики улюбленця, XP та систему рівнів;
- магазин і систему інвентарю;
- нагороди за міні-гру у вигляді монет та XP;
- фонові локації;
- live-оновлення через Socket.IO;
- автоматизовані API-тести;
- GitHub Actions CI для автоматичного запуску тестів.

Для перевірки стабільності alpha-версії використовується автоматизоване тестування.

**Локальний запуск тестів:**

## ⭐ 2. Базова реалізація проєкту у 1 семестрі

MyPet — це повноцінний навчальний Fullstack-застосунок, розроблений у стилі класичних ігор-тамагочі.

**Основна мета проєкту:**

- продемонструвати на практиці фундаментальні принципи ООП;
- реалізувати чіткий поділ на моделі, роути та утиліти;

- реалізувати синхронізацію в реальному часі через WebSockets.

## 2.1 Ігрові механіки

Гравець доглядає за улюбленцем (Кіт, Пес, Мавпа), контролюючи його життєві показники.

| Показник | Діапазон | Опис |
|----------|----------|------|
| Health | 1–100 | Здоров'я. Мінімум 1 (улюбленець не вмирає). |
| Hunger | 0–100 | Голод (0 — ситий, 100 — голодний). |
| Happiness | 0–100 | Щастя. Впливає на здоров'я. |
| Energy | 0–100 | Енергія улюбленця. Витрачається під час активностей та відновлюється під час сну. |
| Cleanliness | 0–100 | Чистота улюбленця. |
| Coins | 0+ | Внутрішньоігрова валюта. |
| XP | 0+ | Досвід, який нараховується за активності. |
| Level | 1+ | Рівень улюбленця, що зростає разом із накопиченням XP. |

## 🏗️ 2.2 ООП Архітектура та Дизайн

### 2.2.1 Інкапсуляція та Моделі

- `backend/models/pet.js` — модель Pet, інкапсулює стани та логіку;
- методи: `pet.feed()`, `pet.live()`, `pet.sleep()`, `pet.finishGame()`;
- Game Loop у `backend/server.js` викликає `pet.live()` через `setInterval`.

### 2.2.2 Поліморфізм

- `applyItemEffects` (`backend/shop/shopItems.js`) працює по-різному для різних типів предметів;
- mini-game використовує різні спрайти залежно від типу улюбленця.

### 2.2.3 Real-Time

- Socket.IO надсилає `pet-update` щоразу після зміни стану улюбленця;
- live-оновлення дозволяють синхронізувати стан між клієнтом і сервером.

## 🚀 2.3 Реалізований функціонал та виправлення

| Функціонал | Файли | Опис |
|-----------|-------|------|
| Кастомні сповіщення | `frontend/script.js` | Стилізовані UI-попапи замість `alert` |
| Видалення улюбленця | `petRoutes.js`, `database.js` | Повне видалення Pet + Purchases + Inventory |
| Фікс здоров’я | `pet.js`, `server.js` | Health не падає нижче 1 |
| Реєстрація та авторизація | `server.js`, `database.js` | Користувач може створити акаунт і увійти |
| Кілька улюбленців | `petRoutes.js`, `database.js` | Один користувач може мати декілька pets |
| XP та level | `pet.js`, `petRoutes.js` | Улюбленець отримує досвід і підвищує рівень |
| Сон улюбленця | `petRoutes.js`, `pet.js` | Відновлення енергії через дію sleep |
| Міні-гра | `frontend/`, `petRoutes.js` | Нарахування монет і XP після завершення гри |
| Магазин та інвентар | `shopRoutes.js`, `inventoryRoutes.js` | Купівля та використання предметів |
| Локації | `frontend/script.js`, `frontend/assets/` | Зміна фону залежно від дії або стану |
| CI для тестів | `.github/workflows/node-tests.yml` | Автоматичний запуск `npm ci` та `npm test` |

## 🤖 2.5 GitHub Actions CI

У проєкті налаштовано GitHub Actions workflow для автоматичного запуску тестів.

Файл workflow:

```text
.github/workflows/node-tests.yml
```

Workflow виконує:

```bash
npm ci
npm test
```

CI запускається при:

- `push` у гілки `main` та `feature/alpha-ci-tests-docs`;
- `pull_request` у `main`.

Це дозволяє перевіряти, що alpha-версія не ламається після змін і готова до merge.
